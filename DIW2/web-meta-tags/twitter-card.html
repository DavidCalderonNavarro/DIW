Twitter Card

Define cómo se ve tu enlace al compartirlo en X (Twitter).

Ejemplo

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Meta tags explicadas">
<meta name="twitter:description" content="Guía de las meta tags esenciales.">
<meta name="twitter:image" content="https://www.ejemplo.com/img/og.jpg">

Cómo funciona

Si faltan, X recurre a las etiquetas Open Graph. Aun así conviene definir twitter:card para elegir el formato.

Recomendaciones

  • summary o summary_large_image.
  • Añade twitter:site con tu @usuario.
  • Añade twitter:image:alt por accesibilidad.
