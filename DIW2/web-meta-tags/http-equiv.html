Meta tag 10 de 11

http-equiv

Simula cabeceras HTTP desde el propio HTML.

Ejemplo

<meta http-equiv="X-UA-Compatible" content="IE=edge">
<meta http-equiv="Content-Security-Policy" content="default-src 'self'">
<meta http-equiv="refresh" content="30">

Cómo funciona

Sirve para refresh (recarga o redirección), Content-Security-Policy y X-UA-Compatible. Siempre es preferible enviar estas cabeceras desde el servidor.

Recomendaciones

  • refresh con redirección hace daño a la accesibilidad y al SEO.
  • CSP por meta no admite todas las directivas.
  • X-UA-Compatible ya es obsoleta.
