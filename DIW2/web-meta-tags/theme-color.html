Meta tag 7 de 11

theme-color

Colorea la barra del navegador en móvil según tu marca.

Ejemplo

<meta name="theme-color" content="#0f766e">
<meta name="theme-color" content="#042f2e" media="(prefers-color-scheme: dark)">

Cómo funciona

Admite el atributo media para definir un color distinto en modo claro y oscuro. Funciona en Chrome y Safari móvil.

Recomendaciones

  • Usa el color principal de tu marca.
  • Define una variante para modo oscuro.
  • Complementa a color-scheme.
