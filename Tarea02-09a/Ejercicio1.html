Formularios

Consiste en recoger información que introduce el usuario mediante campos de texto, casillas, listas desplegables
o botones. Después, esa información se envía para que el sistema la procese y pueda realizar una acción, como
guardar datos, buscar información o registrar a una persona. En resumen, los formularios sirven para facilitar
la comunicación entre el usuario y el sistema de una forma sencilla y organizada.
