GET/POST

Consiste en enviar informacion entre una pagina web y un servidor

Ventajas de GET:

  • Es rápido y sencillo de utilizar
  • Los datos aparecen en la URL y se pueden compartir mediante un enlace
  • Permite guardar las búsquedas en favoritos
  • Es útil para consultar información

Ventajas de POST:

  • Permite enviar grandes cantidades de datos
  • Los datos no aparecen directamente en la URL
  • Es ideal para enviar formularios, registrarse o iniciar sesión
  • Permite enviar distintos tipos de datos, como archivos
